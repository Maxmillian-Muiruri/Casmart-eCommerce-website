
# Casmart Project
➡[View live site]](https://casmart-e-commerce-website.vercel.app/)


## Overview

Casmart is a web project consisting of HTML, CSS, and JavaScript files to create a responsive and interactive website. The project includes a main HTML file, styling with CSS, and client-side scripting with JavaScript.

## Project Structure

- `index.html`: The main HTML file that defines the structure and content of the website.
- `assets/css/style.css`: The CSS file responsible for styling the website, including layout, colors, and responsiveness.
- `assets/js/script.js`: The JavaScript file that adds interactivity and dynamic behavior to the website.
- `assets/images/`: Directory containing images used throughout the website.

## Features

- Responsive design for various screen sizes.
- Interactive elements powered by JavaScript.
- Organized asset management for styles, scripts, and images.

## Usage

1. Open `index.html` in a web browser to view the website.
2. Modify the CSS in `assets/css/style.css` to change the appearance.
3. Update JavaScript functionality in `assets/js/script.js` as needed.

## Development

- Ensure you have a modern web browser for testing.
- Use a code editor like VSCode for editing files.
- Refresh the browser to see changes after editing.
